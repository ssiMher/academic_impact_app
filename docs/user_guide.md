# 网站使用手册

本手册面向使用网页完成学者引用证据分析的组内用户。首页提供“普通论文分析”“学者分析”和“本地 PDF 库”三个入口。

## 1. 开始前检查

管理员应确保 Web 和后台 worker 都已启动。可访问：

- `/health`：应用基本状态；
- `/health.json`：DBLP、OpenAlex 和 LLM provider 配置状态；
- `/providers/health`：provider 详细状态。

页面能打开但任务长期停在 `pending`，通常是 worker 未启动。

## 2. 创建学者分析会话

1. 首页点击“创建学者分析”。
2. 输入英文姓名、中文姓名或 DBLP PID。
3. 中文姓名会转为拼音后搜索 DBLP；英文姓名直接搜索 DBLP 作者。
4. 页面显示同名候选的姓名、别名、DBLP PID、近期论文和 venue。
5. 人工核对后点击“选择此作者并创建会话”。

系统不会自动选择同名候选。DBLP PID 可以使用：

- `70/1741-4`
- `https://dblp.org/pid/70/1741-4.html`
- `https://dblp.org/pid/70/1741-4.xml`

若 DBLP 超时，页面会显示暂时不可用。稍后重试即可，不要把姓名当作 PID 输入。

## 3. 同步论文和扩展引用

进入学者会话后：

1. 检查作者论文列表；若为空或不完整，点击刷新 DBLP 论文。
2. 勾选需要分析的代表性论文。
3. 设置“每篇论文最多扩展引用数”。数量越高，OpenAlex 请求、队列规模和后续 PDF/LLM 工作量越大。
4. 点击扩展引用并构建队列。
5. 在任务区域观察进度；后台 worker 完成后进入论文队列。

建议先选少量代表作验证流程，再扩大范围。不要一开始就对全部论文设置最大引用数。

## 4. 管理论文队列

队列中的每一项是“引用目标论文的论文”，不是学者本人的论文。常见状态：

- `need_pdf`：尚无引用论文全文；
- `manual_pdf`：用户上传 PDF；
- `reused_pdf` / `local_library_pdf`：复用已有 PDF；
- `selected`：将进入分析；
- `skipped`：暂不分析；
- `analyzed`：已经完成全文分析。

可按重要性、第三方引用、自引、PDF 状态等筛选，并批量选择或跳过。优先处理第三方、重要 venue、引用关系清晰且 PDF 可用的条目。

## 5. 获取 PDF

### 5.1 自动查找开放 PDF

点击“自动查找 / 下载所有 PDF”。系统按以下顺序处理：

1. 跳过已有 PDF；
2. 检查已有元数据中的直接 PDF；
3. 检查 arXiv 标识；
4. 使用 Unpaywall 查询 DOI 的开放版本；
5. 对满足严格标题和作者匹配的候选查询 arXiv；
6. 对 IEEE 条目进入可选浏览器下载阶段。

结果中的数字是本轮统计：

- `downloaded`：本轮新增；
- `skipped_existing_pdf`：此前已有且本轮跳过；
- `open_access_downloaded`：本轮开放 PDF；
- `ieee_downloaded`：本轮 IEEE 下载；
- `no_pdf_found`：未发现可直接下载的开放 PDF；
- `failed`：网络、解析或下载失败，可根据原因重试；
- `publisher_page_requires_login`：只有出版商页面，不能合法自动绕过权限。

因此 `downloaded=8; skipped=23` 表示原有 23 篇仍存在，本轮又新增 8 篇，并不是从 23 篇下降到 8 篇。

### 5.2 IEEE PDF

仅当管理员配置了 IEEE 浏览器下载器且服务器有可交互桌面时使用：

1. 点击打开 IEEE 登录窗口；
2. 在专用浏览器完成个人/机构登录；
3. 回到网页点击“检测登录状态”；
4. 显示已认证后点击“继续 IEEE 下载”。

`about:blank` 是 Playwright 新页面的正常初始地址。若服务器无桌面或登录反复失效，请手工下载并上传，不要反复高频请求 IEEE。

### 5.3 手工上传和本地 PDF 库

对于 Elsevier、Springer、ACM 等需要机构权限的论文：

1. 使用页面上的 DOI/出版社链接，在自己的浏览器中合法下载；
2. 对单篇条目点击上传 PDF；或
3. 将文件放入管理员配置的 PDF inbox/本地库，扫描后匹配到队列。

上传前务必核对完整标题和作者。相似主题或标题前缀相同不代表同一篇论文。

## 6. 选择分析范围

勾选 PDF 已就绪的队列条目，然后启动分析。当前推荐：

- `fulltext_template_direct`：全文结合当前模板直接判断，推荐用于正式分析；
- `fulltext_anchor_direct`：优先利用引用锚点验证目标归属；
- `fulltext_direct`：全文直接分析，覆盖更完整但成本较高；
- `candidate_spans`：仅分析候选段，速度快但可能漏证据；
- `fulltext_chunked`：预留选项，尚未启用。

全文过长、PDF 文本提取失败或 LLM 超时，会在任务和分析调试页面显示具体原因。不要仅根据“任务完成”判断是否产生了证据，应检查 `analyzed_count`、`llm_findings_count` 和证据数量。

## 7. 模板和证据复核

模板用于定义希望识别的证据类型。可以启用内置模板或创建自定义模板。修改模板后，可重新判断已有分析结果。

证据页面支持：

- 按正向评价、详细比较、基线、方法基础、理论基础等筛选；
- 查看引用原文、目标锚点、强度和模型理由；
- 标记接受、拒绝、误报或重要证据；
- 添加人工备注和修正标签。

最终报告应优先使用经过人工复核、目标归属明确、正文上下文充分的第三方证据。

## 8. 生成卡片和导出

复核证据后可以生成高亮卡片和报告工作区，并导出：

- `report.md`：Markdown 报告；
- `structured.json`：结构化结果；
- `highlight_cards.csv` / `highlight_cards.md`：证据卡片；
- `report.pptx`：PowerPoint 报告；
- 缺失 PDF CSV：人工下载清单。

导出前建议再次检查误报、作者自引、引用目标错配及 PDF 是否确属该论文。

## 9. 普通论文分析

“普通论文分析”适合围绕单篇目标论文运行：

1. 输入 DOI、标题或 provider 标识创建会话；
2. 发现引用论文；
3. 上传或匹配引用论文 PDF；
4. 运行分析；
5. 查看并导出结果。

大规模学者级分析建议使用“学者分析”，因为它提供队列、批量 PDF、模板、证据复核和报告工作区。

## 10. 常见问题

- 输入姓名没有候选：尝试英文全名或 DBLP PID；中文姓名拼音可能存在多种写法。
- 作者有论文但会话为空：点击刷新 DBLP 论文，并查看 DBLP 是否超时。
- 自动下载开放 PDF 为 0：可能确实没有开放版本，也可能 Unpaywall/arXiv 超时；查看逐篇失败原因。
- 明明在网上看到相似 arXiv 论文：必须核对完整标题和作者，系统不会仅凭关键词相似度绑定。
- IEEE 显示已登录后又等待登录：检查专用 Profile、图形桌面、网络挑战和 worker 是否加载最新代码。
- 页面显示 `partial_success`：部分条目成功、部分失败；已下载的 PDF 不会因此丢失。
- 选择分析后没有结果：确认 PDF 已就绪、条目已选中、worker 正常，并查看分析调试页。
- `database is locked`：联系管理员确认没有多 Web worker、多任务 worker或 SQLite 位于网络文件系统。
